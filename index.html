JsDelivr是一个免费的开源CDN（内容分发网络）服务，专门为npm和GitHub上的开源项目提供快速、可靠的文件托管和分发服务。 https://www.jsdelivr.com/

将自己的 JS 文件放到 CDN 上:

免费方案 (GitHub + jsDelivr)：这是目前很流行的一种零成本方案。开发者只需将 JS 文件托管在 GitHub 的公开仓库中， 然后通过 jsDelivr 提供的特定 URL 即可访问。jsDelivr 会自动抓取你的 GitHub 仓库文件，并将其分发到它们的全球 CDN 网络上 \lt script src="https://cdn.jsdelivr.net/gh/你的用户名/你的仓库名@v1.0/js/my-script.js"> \lt /script>
